# China Inbound Travel Skill

An Agent Skill project for helping international visitors plan and manage travel in China across Codex, Claude, and other `SKILL.md`-compatible agents.

This repository is at the requirements stage. The Skill itself has not been implemented yet.

## Documents

- [Requirements and acceptance cases](docs/china-inbound-travel-skill-prd.md)
- [Research source register](docs/china-travel-skill-research/sources.md)

The first implementation milestone is a small `SKILL.md` and focused references for entry, payment, rail travel, and emergencies. Current policies and platform capabilities must be verified for each trip rather than copied from the research register as permanent rules.
